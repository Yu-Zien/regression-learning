# 回归分析学习室

根据两章回归分析讲义制作的中文学习网站：80 个知识点、80 组 A/B 配对练习、23 项精选回顾。

包含条件分布、最佳线性预测、OLS、有限样本性质、t/F 检验及 GLS，使用本地 MathML 公式和浏览器内学习记录。

## 使用

打开本仓库的 GitHub Pages 地址，从首页开始学习，或从目录查阅课程。长公式在手机上可左右滑动查看。

学习记录保存在当前地址的浏览器中。更换设备、浏览器或从本地网站迁移时，请在旧站“目录与进度 → 进度、设置与备份”导出，再在新站导入。

本仓库只发布生成后的课程网页，不包含原始 PDF、私人学习记录或本地测试备份。原始讲义来源和编辑补充在对应课内注明。

保留的第三方依赖为 ts-fsrs，其许可证位于 runtime/vendor/ts-fsrs.LICENSE。
